# Pixel Art Animation Lab

Local AI-assisted workflow for creating consistent pixel-art character animations for HTML5 games.

## Components

- ComfyUI: Git submodule
- GIMP: image editing and GIF export
- LibreSprite: optional frame-by-frame animation editor

## Project folders

- `ComfyUI/`: official ComfyUI repository
- `models/`: model documentation
- `input/`: source character images
- `output/`: generated frames and animations
- `workflows/`: ComfyUI workflow files

## Notes

AI models and generated assets are stored locally and are not tracked by Git.
